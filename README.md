# Metric-Imperial-Converter

A Python program that converts measurements between Metric and Imperial units across length, mass, temperature, and liquid volume.

## Supported Conversions

### Length
* **m** &rarr; **ft**
* **ft** &rarr; **m**

### Mass
* **kg** &rarr; **lbs**
* **lbs** &rarr; **kg**

### Temperature
* **°C** &rarr; **°F**
* **°F** &rarr; **°C**

### Liquid Volume
* **L** &rarr; **gal**
* **gal** &rarr; **L**
